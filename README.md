# 🚀 Pypsiki in Space

**Система классификации инопланетных радиосигналов с использованием нейронных сетей**

## 📋 Описание файлов

### `main.py`
**Основной модуль бэкенда.** Содержит:
- ✅ Класс `DataNPZLoader` — загрузка и обработка .npz файлов с Яндекс.Диска
- ✅ Класс `SignalPreprocessor` — предобработка сигналов через NumPy/SciPy (FFT, статистика, нормализация)
- ✅ Класс `AlienClassifier` — нейронная сеть на Keras для классификации
- ✅ Функции авторизации — `authenticate()`, `hash_password()`, `verify_password()`
- ✅ Функции работы с БД — `get_db()`, `init_db()`, `create_user()`, `get_user()`
- ✅ Функции аналитики — `plot_accuracy()`, `plot_distribution()`, `plot_predictions()`, `plot_top()`

### `frontend.py`
**Графический интерфейс на PyQt6.** Содержит:
- ✅ `LoginWindow` — окно авторизации пользователей
- ✅ `MainWindow` — главное окно приложения
- ✅ `Dashboard` — дашборд пользователя (загрузка данных, обучение, классификация, графики)
- ✅ `AdminPanel` — панель администратора (создание/удаление пользователей)
- ✅ `TrainThread` — поток обучения модели (без блокировки интерфейса)
- ✅ `MplCanvas` — холст для отрисовки графиков matplotlib

### `config.py`
**Файл конфигурации.** Содержит:
- ✅ Пути к данным и моделям
- ✅ Параметры обучения (`EPOCHS=20`, `BATCH_SIZE=32`)
- ✅ Цветовая схема тёмной темы

## 🔧 Предобработка данных

Класс `SignalPreprocessor` реализует:

| Метод | Описание |
|-------|----------|
| `normalize_signal_length()` | Приведение всех сигналов к единой длине (интерполяция) |
| `remove_noise()` | Удаление шума (значения < порога обнуляются) |
| `extract_fft()` | Извлечение частотных признаков через FFT |
| `extract_stats()` | Статистические признаки (mean, std, min, max, median, skew, kurtosis...) |
| `smooth()` | Сглаживание сигнала скользящим средним |

## 🧠 Нейронная сеть

**Архитектура `AlienClassifier`:**

```
Input → Dense(256) → BatchNorm → Dropout(0.4) →
        Dense(128) → BatchNorm → Dropout(0.3) →
        Dense(64)  → BatchNorm → Dropout(0.2) →
        Dense(32)  → Dense(classes, softmax)
```

**Параметры:**
- Оптимизатор: `Adam`
- Функция потерь: `sparse_categorical_crossentropy`
- Метрики: `accuracy`
- Эпохи: `20`
- Размер пакета: `32`

## ⚠️ Важные замечания

1. **TensorFlow DLL ошибка в pytest:** Известная проблема совместимости TensorFlow с Python из Microsoft Store на Windows. Основное приложение работает корректно.

2. **Длина сигналов:** Система автоматически приводит все сигналы к единой длине через интерполяцию.

3. **Восстановление классов:** Функция `extract_class()` извлекает названия цивилизаций из строк вида `hash+ClassName` (например: `a32f08ce7f57128fcefaa39517fb7a24Kepler-62e` → `Kepler-62e`).

4. **Сохранение модели:** После обучения модель автоматически сохраняется в папку `models/`.
